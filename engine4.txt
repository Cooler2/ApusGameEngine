Новая архитектура движка (Engine-4)

TGameObject -> TBasicGame 
 Класс реализует общую функциональность игры: инициализация, главный цикл, управление сценами
 
TPlatform (Windows/SDL/Android/iOS)
 Здесь все платформозависимые функции, которые используются классом Game для таких вещей как 
 - создание окна, управление им
 - инициализация графического API (получение контекста OpenGL)
 - получение и обработка событий ввода/вывода
 - управление экранной клавиатурой (для мобилок)
 
TGraphicsAPI (OpenGL/GLES/Direct3D/Vulcan etc)
 обёртка для графического API: 
 - отрисовка примитивов
 - матрицы трансформации
 - создание текстур
 - шейдеры
 
TPainter 
 Платформонезависимый интерфейс для отрисовки различных примитивов
 
TTranslationEngine 
 Подключаемый интерфейс для локализации строк (обёртка для UDict)
 
TTextDrawer
 Система отрисовки текста.
