# redist/windows provenance - third-party runtime DLLs committed to this repository.
#
# Unlike the other platform directories, the binaries are NOT stored here: they
# live where the build output expects to find them (bin/, bin64/, Base/bin/,
# Base/tests/). Copying them here as well would double their weight in the
# repository for no benefit. This file records where each one came from;
# licenses/ holds the upstream license texts.
#
# Every hash below was verified by re-downloading the upstream artifact and
# comparing: unless a "normalization" line says otherwise, the committed file is
# byte-identical to the one the upstream project published.

# Reproducing / auditing
# ----------------------
# There is no fetch script for this platform (the DLLs are not re-vendored into
# this directory, so there is nothing to normalize into a canonical layout).
# To re-verify, download the archives named above and compare hashes, e.g.:
#
#   curl -LO https://github.com/libsdl-org/SDL_mixer/releases/download/release-2.8.1/SDL2_mixer-2.8.1-win32-x64.zip
#   unzip -o SDL2_mixer-2.8.1-win32-x64.zip
#   sha256sum SDL2_mixer.dll optional/libxmp.dll
